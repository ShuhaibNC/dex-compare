Supported input files

APK, XAPK, APKS, APKM, ZIP, and DEX files. APK bundles and split APKs are read directly; no Android SDK or external decompiler is required.

Comparison engine

Compares DEX class, method, and field definitions, then disassembles method bytecode for normalized Smali comparison.

  • Ignores debug metadata, comments, and no-operation instructions.
  • Normalizes register numbering and equivalent constant, branch, and invoke encodings.
  • Shows method changes as unified or side-by-side diffs.

Implementation

Desktop interface powered by Electron. The DEX parser, archive reader, comparison engine, and Smali formatter are implemented in JavaScript.
